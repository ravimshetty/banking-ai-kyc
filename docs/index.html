Sign in as a customer or a member of bank staff and talk to the assistant. A customer service agent and a KYC/AML compliance agent do the work, but every request first passes guardrails and an access check, anything irreversible waits for an authorised person, and every step is written to an audit log. The strip under each answer shows exactly where a request went through or was stopped.

    This page runs the assistant's rules in your browser on a small synthetic slice of the project's data: eight fictional customers, about 600 transactions and a five-name demo sanctions list. No real customer data or bank is involved. The full project runs the same logic on PostgreSQL with a FastAPI service, database-enforced access control and 28 automated tests.

    Built with Python, FastAPI, PostgreSQL, deterministic tools with an optional LLM router, TF-IDF retrieval with citations, and Docker.
